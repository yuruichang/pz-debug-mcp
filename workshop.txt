description=[h2]功能[/h2]
description=[list]
description=[*]浏览原版 Debug 接口目录，读取审核范围内的玩家、世界、气候、沙盒、车辆等数据，以及 Java 对象字段和模组状态。
description=[*]查询 JVM 线程、调用栈、堆与 GC、加载类、补丁声明及变换证据，支持有界方法追踪。
description=[*]支持 Java/Lua 断点、暂停栈、局部变量、单步与继续；Windows 原生调试支持模块、符号、寄存器、机器码断点和有限内存读取。
description=[*]后台持续采集并在本机保存；MCP 服务保持运行时自动归档，支持分页、历史记录和按需查询。
description=[*]自动关闭失焦暂停，切换到 AI 工具时游戏可继续运行；保留手动暂停与断点暂停。另提供预定义测试与受控 Lua 重载。
description=[/list]

description=Connect an MCP-compatible AI client to Project Zomboid to inspect built-in Debug data, Java mods and JVM state in a test save, and retrieve local records on demand.

description=[h2]A separate MCP program is required[/h2]
description=[b]After subscribing to the Workshop mod, you must also install the local MCP program separately.[/b] The mod handles the in-game bridge and data collection. The separate MCP program exposes tools to your AI client, reads bridge data and archives records. Your AI client launches it through stdio.
description=[url=https://github.com/yuruichang/pz-debug-mcp]GitHub: MCP program source and installation instructions[/url]
description=[url=https://github.com/yuruichang/pz-debug-mcp/blob/main/README.en.md]English installation and connection guide[/url]
description=The repository currently requires access permission. Obtain the source and configure MCP before testing the connection in game.
description=
description=[h2]Features[/h2]
description=[list]
description=[*]Browse the built-in Debug API catalog and read player, world, climate, sandbox and vehicle data under reviewed access rules, plus Java object fields and mod state.
description=[*]Inspect JVM threads, stacks, heap and GC, loaded classes, patch declarations and transformation evidence; use bounded method tracing.
description=[*]Set Java/Lua breakpoints, inspect paused stacks and locals, step and resume. Windows native debugging supports modules, symbols, registers, machine-code breakpoints and bounded memory reads.
description=[*]Collect data continuously in the background and save it locally. A running MCP service automatically archives records for paging, historical access and on-demand queries.
description=[*]Automatically disable pause on focus loss so the game can run while you switch to your AI client. Manual and breakpoint pauses are preserved. Registered tests and controlled Lua reloads are also available.
description=[/list]
description=
description=[h2]Requirements and setup[/h2]
description=[list]
description=[*]Verified versions: Project Zomboid 42.21.0, Java 25, ZombieBuddy 2.3.2 and its Java Agent.
description=[*]The game machine needs Python 3.11+, the separate MCP program and an MCP-compatible AI client. The native debugger targets Windows.
description=[*]Building from source requires a full JDK 25, Visual Studio C++ Build Tools and the Windows SDK.
description=[/list]
description=[olist]
description=[*]Install ZombieBuddy and its Java Agent, then enable ZombieBuddy and PZDebugMCP in game.
description=[*]Obtain the source from GitHub and follow the README to run setup.ps1 -Development and build.ps1. Set -GameDir to your actual game installation directory when building.
description=[*]Add the pz_debug entry from the generated mcp-config.json to your AI client's MCP configuration. --zomboid-dir points to the game cache, not the Steam installation. If you use -cachedir, keep these paths consistent.
description=[*]Fully restart the game with -debug, approve the updated PZDebugMCP.jar and enter a test save. Call pz_status to confirm an online bridge and Debug mode before querying data.
description=[/olist]
description=
description=[h2]Debugging and recording limits[/h2]
description=For Java breakpoints, exit the game, run enable-debugging.ps1 and restart. JDWP listens only on the loopback address 127.0.0.1:8801 by default. Native source locations, private types and local variables require matching PDB symbols.
description=Game-side recording uses a bounded rotating buffer. Keep the MCP service connected from the start of debugging to preserve the full history of received records. Unreviewed methods are not executed; unloaded areas and missing symbols cannot be reconstructed. Servers need the MCP program running on the server machine with access to its cache.
